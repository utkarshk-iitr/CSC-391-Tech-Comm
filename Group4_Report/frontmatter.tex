\begin{abstract}
\addchaptertocentry{\abstractname}

Modern software applications need external libraries and package management systems to function properly. The software development process has become faster due to this requirement but the software supply chains now face increased cybersecurity threats. The report investigates main cyber threat categories which lead to a detailed examination of software supply chain attacks as a critical threat that affects entire ecosystems.

The report presents: (i) an overview of malware, phishing, denial-of-service, insider threats, and supply chain attacks; (ii) a case study of the 2024 XZ Utils backdoor incident; (iii) a review of related research, including MALOSS and dependency confusion analysis; and (iv) a comparative discussion of existing and proposed mitigations, including eBPF-based monitoring, static analysis, and symbolic execution assisted triage.

The main result of our research demonstrates that trust acts as the main vulnerability that cyber attackers use to breach software supply chains. Organizations need to establish multiple protection mechanisms which include security measures for maintainers registries developers and deployment pipelines. The report closes with practical future directions: dependency provenance verification, stronger release integrity checks, continuous monitoring, and faster ecosystem-wide response to newly discovered malicious packages.
\end{abstract}
